# AI Engineer Learning Path

A comprehensive, multilingual web application to guide aspiring AI Engineers through their learning journey.

## Features

- 🌍 **Multilingual Support**: English, Spanish, Chinese, and French
- 🎨 **Beautiful UI**: Colorful, dynamic design with smooth animations
- 📚 **Comprehensive Content**: Detailed learning path with resources and roadmap
- 🚀 **Optimized for Vercel**: Built with Next.js for easy deployment
- ☕ **Support Option**: Integrated Stripe donation link

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build

```bash
npm run build
npm start
```

## Deploy on Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/mitre88/IA_engineer)

The easiest way to deploy this Next.js app is to use the [Vercel Platform](https://vercel.com/new).

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Internationalization**: next-intl
- **Icons**: Lucide React
- **Language**: TypeScript
